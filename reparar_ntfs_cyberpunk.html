1. Detectar el problema

- En Linux: error $MFTMirr does not match $MFT. - En Windows: pide reparar la unidad al conectarla. - Síntoma: aparece el disco pero no se puede asignar letra en Administración de discos.

2. Reparar con TestDisk (Linux)

sudo testdisk - Selecciona el disco dañado. - Analyse → Quick Search para detectar particiones. - Si aparece la partición NTFS, pulsa P para listar archivos. - Si los ves, pulsa q para salir y luego Write para reescribir la tabla de particiones. - Reinicia el sistema.

3. Reparar con CHKDSK (Windows)

- Conecta el disco en Windows. - Si pide reparar, abre CMD como administrador: chkdsk /f D: *(reemplaza D: por la letra asignada)* - Reinicia Windows. - El disco debería funcionar en Windows y Linux.

4. Prevención

- Usa un adaptador USB–SATA confiable. - Siempre expulsa el disco antes de desconectarlo. - Si lo usas en Windows, Linux y Google TV: considera exFAT para mayor compatibilidad y menos corrupción.

5. Formatear a exFAT (opcional)

En Linux: sudo mkfs.exfat /dev/sdX1 En Windows: - Explorador → clic derecho en el disco → Formatear → exFAT.
